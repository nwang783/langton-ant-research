# Status taxonomy

- **OPEN / UNSOLVED:** the stated obligation has not been proved or refuted.
- **ANALYTICALLY REVIEWED:** a written argument was checked within this investigation, under its stated hypotheses. This is not external peer review or formal proof-assistant verification.
- **EXACT CERTIFICATE CHECKED:** a finite or all-parameter certificate has an identified checker, dependencies, hashes, and a successful audit. Its quantifier scope comes from the accompanying analytic reduction, not from the number of simulated steps.
- **CONDITIONAL / SCOPED:** valid only under explicit hypotheses, a restricted language, architecture, fixed cohort, geometry, cap, or parameter range. It cannot be promoted to the unrestricted ant.
- **FINITE CONTROL / ENUMERATION:** a completely specified finite computation. Exhaustiveness applies only to the explicitly enumerated domain.
- **AUTHOR RESULT / PENDING AUDIT:** proposed or recorded, but not independently signed off in the retained audit record.
- **REJECTED / SUPERSEDED:** a claim or metadata statement has a documented counterexample, scope failure, or later correction. Preserve it with the correction so the same error is not repeated.
- **INCONCLUSIVE / TIMEOUT / UNKNOWN:** no mathematical exclusion follows.
- **REPORTED UPSTREAM:** a cited source states the result. Its trust boundary and any missing independent rebuild must remain visible.
- **INTEGRITY VERIFIED:** bytes match the stated digest. This is not evidence that the claim is true.

Historical terms “signed” and “PASS” mean the recorded internal mathematical audit accepted that exact artifact and scope. They are not cryptographic signatures, peer-review endorsements, or automatic proof of every claim in the directory. Check later entries for mandatory qualifications.

No repository-wide “proof passed” label is justified. The universal canonical-104 claim remains UNSOLVED.
