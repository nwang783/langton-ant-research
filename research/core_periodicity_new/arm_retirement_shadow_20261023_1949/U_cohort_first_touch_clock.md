# Exact first-touch clocks for intact U-family output cohorts

## Statements

Work inside an actual complete recurrent-eight factor. Let S be a genuine full U, UC, or UCC producer, with source-entry C clock zero and C-tail count c in {0,1,2}. Let R be its exact 9+3c fresh output identities. If any later full packet consumes an identity of R, let P be the first such consumer.

1. P begins at one of the following source-entry C clocks:
   - U source: 2, 4, or 5.
   - UC source: 2, 4, 5, or 6.
   - UCC source: 2, 4, 5, 6, or 7.

   In particular, first touch is at most five C units after S's full exit. If the entire cohort remains the same current identities while the C clock advances strictly beyond this threshold, it stays wholly untouched for the rest of the retained factor. The strict threshold matters: arbitrarily many zero-C packets can occur at the boundary clock.

2. If P itself is U-family, then at least one of P's upper inputs outside R is already current immediately before S enters. Thus P uses a genuinely precreator identity, not only an identity outside the producer cohort.

Neither statement identifies a distinct original historical component. The older upper identity may already share S's larger historical component. Neither is a global U-chain birth bound.

## Current output-tree Jordan clock

Write doubled corrected centers. The source U chord midpoint is W=(-1,3). For each of the 56 poses, the consumer's first atomic base has a contact vertex E in the source output graph. There is a simple source-output path from E back to W such that:

- the entire consumer base meets that path only at E;
- the actual source U remainder and complete C tail meet it only at W;
- nonadjacent path edges do not meet.

The data records every valid such bridge. Every edge is one of the original source output identities, current through the first-touch hypothesis. The signed current-edge barrier therefore keeps intervening future atomic centers off the bridge. The pre-full-installation source U/C-tail interface is checked directly, not inferred from later freshness. U-entry suffix simplicity makes the closed arc Jordan.

Let alpha be the consumer-base chord angle in normal heading: pi/4 for D, atan(3) for V, and pi/2 for U. The exact atomic principal-turn lift from source midpoint to E is

    n*pi/2 + alpha - pi/2.

Every closing edge is diagonal. Exact symbolic angle bookkeeping records each bridge join as an integer multiple of pi/4 plus an integer multiple of atan(3). The latter coefficient cancels the V alpha when present. The total closed turn is (n+m)*pi/2 for the recorded integer m. Jordan turning gives n+m=+4 or -4. In each pose there is exactly one nonnegative solution with the required heading congruence. These solutions are precisely the clocks in the statement above; all are at most c+5.

The checker uses only the exact interval pi/4 < atan(3) < pi/2 to select principal turns. No floating-point angles enter this certificate.

## A first U-family consumer imports a precreator upper

Of the 40 geometrically surviving U-family poses, ten would use the source recycled output (-1,2), contrary to the signed all-age recycled-q-to-U exclusion. Three would consume four identities from this one full producer, contrary to the signed max-three theorem. This leaves 27 necessary poses.

For each of these 27, at least one upper input lies outside R. Every genuinely later full producer of that input must start at clock at most n-5, by the signed produced-upper minimum age five.

If n-5<c, no producer starting after S's full exit can meet this deadline. No distinct full producer starts inside S itself, and the selected cell is not a full output of S. Its final identity therefore predates S's entry and remains current through that entry.

The only exceptional clocks have n=c+5. Normalize the coordinate frame at S's full exit. A producer starting after S at the same C clock c can only follow zero-C packets, hence has normal heading N and entry y>=0. Its literal outputs all have y>=0. Equality y=0 requires the producer to be the immediate successor at the source exit, because every zero-C packet has strictly positive normal y displacement. At local output y=0 the only possible cells for any retained producer are (0,0), (1,0), and (2,0).

For every exceptional pose, an outside upper witness is either behind this forward frontier with y<0, or is (3,0). Such a cell cannot be produced by any later clock-c producer. It too must already be current before S's entry. The 27 witnesses and their exact source-exit coordinates are recorded.

This is a first-consumer statement. If some different cohort output has already retired, the held-output Jordan bridge may no longer exist and the argument cannot simply be reused for a later consumer.
