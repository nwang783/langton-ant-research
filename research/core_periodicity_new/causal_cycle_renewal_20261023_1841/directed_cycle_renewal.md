# Directed first retirement of a U output cycle

23 October 2026, 18:44 UTC. Author exact finite derivation, independent review requested. This is a genuine ordered-identity port law, not a historical component merger or global U-count bound.

## Statement

Consider a physically actual complete recurrent-eight factor containing a creating U, UC, or UCC packet. Restrict to the actual suffix starting with that packet; signed U-entry simplicity makes its corrected atomic-center path injective. Normalize the creating U entry to head (0,0,N). Its U base installs the four exact residual cycle identities at

    Z = {(1,0),(1,1),(2,0),(2,1)}.

Its internal C tails do not touch those identities. If any identity of Z ever retires inside the same complete-eight suffix, their first retirement is necessarily in U/UC/UCC at head (3,-1,N). That consumer retires exactly the two source east-column identities (2,0),(2,1), as its lower inputs a,q.

Consequently the two east-column identities always survive together. Each has precisely this one possible consuming pose and slot: neither can be consumed by D/V, individually, as an upper U input, or after first breaking the cycle elsewhere. If either east identity is still current, ALL FOUR original cycle identities are still current.

Every current source cycle has at most one first-breaking successor, and one U can first-break at most one such current cycle. Links from a creating U to its first breaker therefore form disjoint chronological directed paths. Along any path, heading is constant and successive U entries, and successive cycle centers, translate by rotation_heading(3,-1). These paths may in principle be arbitrarily long; no finite resource bound follows merely from this monotonicity.

Exhaust all 23 retained true input slots in four headings, placed at w: 92 alignments. Forty-six have wrong sector; 37 have a literal complete context touching a protected Z cell. 5. The left candidate U/UC/UCC(0,2,S) requires w before-white. Since w cannot retire strictly before this first cycle breaker, this is impossible. Only the right candidate (3,-1,N) remains.

The east-pair consequence needs no extra enumeration: a prior first cycle break would consume both east identities. Therefore neither east identity can outlive such a break, and its own eventual first retirement must be that same right gate.

Distinct intact cycles born in different packets have disjoint current identity/cell sets. A fresh output cannot overlap an unretired old residual identity. Since any U first breaker must use its one specific lower pair for each old cycle it breaks, it cannot first-break two of them. Thus intact-cycle count equals U births minus first breakers and is nondecreasing, NOT finite fuel.
