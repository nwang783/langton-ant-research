## Finite graph premise

Use the272 producer-output roles and35,904 fundamental edges in the frozen `genealogy_saturation_roles_frozen_20261023_0833/manifest.json`. A role is(packet,local output slot,birth heading). An edge joins a produced auxiliary parent identity to a child output via the chosen input of that child's packet. It retains source-start C gap n, exact heading congruence, physical checkerboard sector, JO/KV input ages, and every applicable signed protected HB or exact0..4/overflow>=5 counted exclusion. No unexcluded transfer is claimed physically realizable.

For each role pair, the graph keeps the smallest unexcluded gap n. All larger gaps in its heading residue add multiples of4; for the upper inequalities below they only enlarge the right side, whether or not the larger transfer itself is excluded. Completely forbidden role pairs are omitted. Thus every genuine produced-parent ancestry edge is covered.

## A strict per-generation deficit, not a global fuel bound

The frozen role graph's zero-margin KY subgraph is acyclic, with a rank r in{0,1,2} decreasing on every tight edge. Define Psi(role)=3*Phi(heading)+r(role), using Phi=(0,5,6,3). Every allowed edge then satisfies

12*dy+1 <=9*n+Psi(parent)−Psi(child).

For a non-tight edge the integer KY margin is at least1, and the rank change is at least−2; for a tight edge the rank drop is at least1. Summation yields

12*DeltaY+N <=9*DeltaC+Psi(start)−Psi(end)

for N produced-parent generations. This is a genuinely strict ancestral rank. It still is not nonreplenishable global fuel: DeltaC is unbounded, branching is not charged by one common finite budget, and the2/3 critical role cycle can repeat inside the supplied RELAXATION. A finite number of initial roots does not bound descendants. Any confinement proof needs an additional simultaneous-ledger/chronology/white-context relation, not just a smaller positive speed coefficient.
