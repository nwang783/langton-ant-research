## Literal C, without inventing a standalone-C language theorem

The common C raw word is the fifteen-letter suffix of DC. Reconstructing its
RAW+M11 demands gives precisely the five entry-core black cells, with every
other demanded cell white. It has endpoint(0,1,W), NO residual inputs, and
fresh residual outputs(1,2),(2,0),(2,1). Its exit bud is(1,2). Thus C preserves
all old current residual identities and adds these three; it never silently
retires one. This is direct literal geometry, not a counted-kernel assertion.

The base D,V,U buds are their full local output slots(2,0),(2,2),(1,3).
Each attached C begins with M11, so the base and each nonfinal C prefix is an
actual complete raw-plus-marker context. Repeated C tails preserve all prior
base/prefix residuals by the preceding literal rule. Each new bud is distinct
from the current old residuals at its atomic installation.

## Full-producer query proof of maturation

A full source packet starts at C clock tau and contains c Cs. At its atomic
prefix j (j=0 after the base, j=1/2 after C atoms), the atomic exit clock is
tau+j. Its bud is one of fifteen fixed FULL-source output roles. These are
explicitly reconstructed from the literal endpoints; no prefix is falsely
renamed a separate maximal retained producer.

A later base consumer with zero,one or two additional post-exit Cs would
have full-source-included C age n=j,j+1,j+2. If n<c, it would have to precede
the full source's exit; the only remaining atoms there are C and have no inputs.

## Rolling two-C spatial injectivity

For any consecutive atomic exits whose C-clock span is at most two, all exit
bud CELLS are pairwise distinct and all their identities remain current at the
last exit. Indeed an earlier bud could not yet have been consumed, while a
later atomic output must be fresh and disjoint from current old residuals.
This is an actual cell-level consequence at base and internal-C cuts, not an
assumption that coarse head segments never cross. It gives no uniform bound
on the number of windows, their current mass or total C count.

VCC(2,5),UCC(1,6): those require full-source age at least five and give eleven
U-goal forbidden internal-cut ports. The present uniform atomic maturation
only guarantees three further C turns after each atomic exit; it is not a
