# Anchored full-chronology exclusion for one protected DC-to-D transfer

Status: candidate exact finite-state certificate, submitted for independent audit at 2026-10-22 23:59 UTC. Not yet signed. This is ONE producer-to-consumer exclusion within the D/C/V recurrent packet language. It is not a D/C/V finite-fuel theorem or a global highway proof.

## Target and allowed context

Use the literal packet words and actual M11 right markers in `../word_stabilization/seven_sub_dcv_port_quotient.json`. The recurrent packet types are D, DC, V, VC, VCC. The previously signed boundary-exception analysis permits restarting an infinite D/C/V tail so only these types occur.

Consider a source DC packet at physical pose (0,0,N) and a later target D packet at (2,2,N). The source's residual output q=(2,3) is black after the source RAW word. Assume it survives as a residual token until the target consumes it as its local (0,1) input. The signed residual-token model says EVERY strict intermediate packet's RAW plus actual M11 context avoids q. No assumption about first-read freshness of other cells is made.

The proposed conclusion is that no such finite packet interval exists. Its proof is an exhaustive closure of a finite, conservative abstraction that retains all temporal updates on a particular patch, not a bounded physical-prefix search.

## Exact patch initialization

Let P be the set of cells read by the source's concatenation RAW(DC) M11. It has 18 cells:

    (-1,-1), (-1,0), (0,-1), (0,0), (0,1), (0,3), (0,4),
    (1,0), (1,1), (1,2), (1,3), (1,4),
    (2,0), (2,1), (2,2), (2,3), (3,1), (3,2).

For each cell in P, the first letter in the concatenation fixes its color before RAW(DC): L means black and R means white. Toggle those fixed bits by the source RAW odd-read mask. This gives the EXACT colors on all of P immediately after RAW(DC). It is valid even for cells first read only by the following marker: their entry colors were forced by the actual complete context, and the RAW parity transfers them to the source endpoint.

At the source endpoint the head is (1,2,W). There are no unknown patch bits. Unread cells outside P are wholly unrestricted.

## Finite position quotient

Let H be all sector-compatible physical poses (p,h) for which at least one of the five recurrent packet contexts, based at (p,h), reads a cell of P. Each such pose is explicitly generated by placing one context cell on one patch cell. Thus H is finite; here |H|=196.

Any packet entry pose outside H has a complete context disjoint from P and consequently leaves every patch bit unchanged. Collapse all such entry poses to the one position OUT.

For each near entry pose and each packet, retain its exact endpoint if that endpoint is in H, and otherwise send it to OUT. From OUT permit a transition, without changing any patch bit, to EVERY pose s in H that can be the endpoint of any recurrent packet whose starting pose lies outside H. There are 76 such reentry poses. This overapproximates an arbitrarily long outside excursion: take its last outside packet before the first return to H. It need not satisfy any remembered outside guard or avoid any other source scar. The enlarged transition set is intentional.

A real trajectory can also stay outside H for multiple packets. These packets make no patch change and are represented by remaining at OUT; no explicit OUT self-loop is needed for reachability. If the source endpoint or target entry were outside H the same quotient would apply, but both are near in this certificate.

## Exact near transitions and permitted deletions

A state consists of one pose in H union {OUT} and the 18-bit patch coloring. For a packet A at a near pose, compute from the literal word:

1. The entry color required at every first-read cell of RAW(A) M11.
2. The RAW(A) odd-read mask.
3. The RAW(A) endpoint pose.

Permit the packet only if its required entry colors agree on the cells in P. Ignore every color requirement outside P. Toggle precisely the restricted RAW odd mask. Thus every concrete feasible packet is represented, but spurious packets caused by forgotten outside bits are allowed.

For strict intermediate packets additionally require:

- Their COMPLETE contexts avoid q.
- The source-to-intermediate pair is not in the signed ordinary forbidden-pair relation, nor in the signed protected-q relation.
- The intermediate-to-target pair is likewise not forbidden, after expressing the target pose and q in the intermediate packet's own rotated/translated frame.

These deletions are sound: q is black after the source and after each intermediate; every intervening strict packet avoids it. Thus both protected-pair premises hold. Ordinary forbidden pairs need no protection premise. A missing finite candidate is never treated as forbidden.

The target D at (2,2,N) is an accepting action whenever its actual RAW+M11 entry requirements agree on P. It is allowed to read q. Forgetting outside requirements makes target acceptance easier, not harder.

The relations used are exactly `seven_sub_dcv_star4_kernel.tsv` (ordinary 3,873 rows) and `dcv_protected_patch2_kernel.tsv` (protected 102,122 rows), already independently replayed in audit.md FO. The abstract search uses only the first five and first seven relation fields respectively, which encode the signed forbidden normalized tuple.

## Finite closure calculation

The generator saves the complete patch, poses, initial bit mask, transitions, and OUT reentry set in `protected_patch_source.json` and the compact integer format `protected_patch_source.dat`.

The exhaustive dense BFS represents a state by

    state_id = position_index * 2^18 + black_bitmask.

The initial patch is fully fixed, so there is exactly one initial state. The finite graph has at most 197 * 2^18 states. The candidate calculation reached 10,768,169 states in 141 BFS layers. The final frontier was empty; no accepting target action was available. The run did not stop at its 50-million-state safety cap and did not reach the uint16 distance limit.

Files:

- `probe_protected_patch_generate.py`: literal geometry and abstraction construction.
- `probe_protected_patch_bfs.cpp`: exhaustive dense BFS, including abstract-witness reconstruction if a goal exists.
- `protected_patch_source.json`, `protected_patch_source.dat`: exact graph specification.
- `protected_patch_source_bfs.txt`, `protected_patch_source_bfs.log`: terminal status and layer counts.

For an independently checked no-hit closure, every actual target interval would map to a path from the initial abstract state to an accepting action, contradicting exhaustion. Therefore the one specified transfer is excluded.

## Limits and next obligation

This retains chronological patch colors, unlike a pairwise patch relation or a bound on interval length. OUT is deliberately permissive, so an abstract witness in another case would not be an actual feasible ant interval. A resource-capped search would prove nothing. This is one previously unresolved transfer pose, but it is NOT itself among the 69 weight-violating poses for the fixed potential. Its DC-target extension is one of those 69 and is being tested separately by the symbolic analysis. No other transfer is inferred from this calculation except exact consequences justified separately. Independent implementation replay and soundness review are required before using this exclusion in the potential proof.
