usual sector, ordered residual identities, and source-included / consumer-excluded

head + rotation(−1/2, −1/2). At a chronological first center contact, select the
outgoing earlier chord and incoming later chord, so their parameters satisfy
0 <= s < 1 and 0 < t <= 1.

Suppose their entry C clocks differ by three and the contact is not a proper
transverse interior crossing. After normalizing the earlier atomic entry to
(0, 0, N), the only possible pair is:

- Earlier atom: the V base of a full V, VC, or VCC packet.
- Later atom: a plain D at (−1, 0, E).
- The later D consumes the earlier full packet's original output (0, 0), with
  exact source-included age three.

All other canonical nonproper three-C geometries are excluded. The conclusion
is a necessary gate, not a no-contact result. It does not require or assume
another complete packet after the later D. In particular, an actual terminal

D, VCC, VC, D is a nine-black-cell control with the earlier V source in the
second full packet. Both have the specified endpoint touch as their first

## Exclusions

1. For any earlier atom, C at (−1, 0, E) requires the fresh common source output
   (2, 0) white. That identity remains current before this target: atomic
   maturity excludes retirement before clock three, and an E retiring base at
   clock three exits with x >= 2. Subsequent E zero-C motion cannot reach a
   target with x <= 1. This is the same endpoint argument bound in signed 1344,
   with the sharper target inequality written explicitly here.

2. V at (−3, 0, E) requires its selected input at the old atomic-core cell
   (−1, −1). This cell is absent from every possible containing full packet's
   final output set. If the source has remaining Cs, any later birth occurs
   after clock zero. If it has none, it is a zero-C N base with exit y >= 1;
   subsequent clock-zero N entries move upward, and every full packet's output
   offsets have y >= 0. They cannot create the cell behind the exit. Therefore
   any actual residual identity there has age at most two, below the selected
   V-family minimum three. The old core cannot supply an entry-identity
   exemption.

3. U at (−4, −1, E) requires its upper input (−1, 4) at old atomic-core cell
   (0, 0). Any new identity has full-source age at most four, including the
   possible second-C clock shift. Its signed produced minimum is five.
   U at (−2, −1, E) instead requires the still-current common output (2, 0)
   at that upper slot; its full-source age is again at most four.

4. D at (−1, 0, E) requires input at old core cell (0, 0). For an earlier D
   or C, the same behind-the-N-exit argument makes every replacement too young.
   For an earlier V or U base, (0, 0) is a genuine fresh source output. No later
   replacement can have age three, so the original must survive. All 12 exact
   counted queries then leave only V/VC/VCC to plain D: all U-family sources
   and all DC target tails are excluded.

5. In the extra U-to-D and U-to-V cases, the target requires source input
   (0, 2) or (−1, 1), respectively. U explicitly retires that identity, and no
   containing full U packet outputs the cell. A later clock-zero N producer
   cannot reach behind U's exit y = 4, so a replacement has age at most two.
   The respective produced minimum is three. The extra U-to-U case similarly
   needs retired (0, 2) at an upper slot, whose minimum five cannot be met.

6. In the extra U-to-C case the target requires source output (0, 1) white.
   The complete 276 timing / sector / counted cases exclude every retirement
