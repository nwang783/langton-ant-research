# Backward local realizability with rectangular outside regions

This is a soundness protocol for the new research checkers, not a new exclusion
certificate. Full-five runs have so far produced only abstract witnesses or
resource caps. A future exclusion still requires independent implementation audit.

## Same finite abstraction, reversed

`bdd_macro_backward_ports.py` reverses the existing oriented-OUT last-writer
abstraction. A state contains a head region, a necessary macro-DFA state, and
a complete assignment of the tracked physical cell colors. Each macro edge has
an entry-color cube and an XOR flip mask. Backward propagation is therefore

    preimage(S) = flip(S, mask) intersect entry_guard.

It is additionally intersected with the source port-color guard. The target is
the entry guard of V at the designated target pose. Acceptance intersects a
state's colors with the forward last-R source cubes. Intermediate macros are
required not to read the marked cell, since its last earlier read defines the
source macro. Reversing does not strengthen this abstraction; it can be much
cheaper because the target guard is restrictive. In controls, the full-five
25-cell abstract witness appeared in 3 seconds rather than a large forward
closure, while the C/V/B exclusion was reproduced.

## Rectangular compactification

`bdd_macro_compact_backward.py` retains all exact coarse centers inside the
smallest rectangle containing every center whose C/U/V/Q/B footprint can read
the tracked patch. It also retains four strips and four corner regions. Each
coordinate is either an exact integer in [lo,hi], the half-line (-infinity,lo-1],
or the half-line [hi+1,infinity). These coordinate regions are paired with the
heading.

Every outside region is certified unable to read a tracked cell: the list of
sensitive centers was generated by solving every rotated/translated macro-read
incidence equation. Thus an outside macro changes no tracked color. Its
geometric image is computed by translating each coordinate interval by the
macro's exact coarse displacement and enumerating intersected regions. This
one-step region image is exact. Composing it may forget unbounded distances,
so paths are still conservative and can still be spurious.

A finite exact head has one successor region. A strip/corner can have several,
but cannot jump to the opposite side under a forward displacement alone. This
removes the simplest oriented-OUT teleports without assuming bounded retreat.

The source cubes additionally enforce a compatible source-entry port history,
and the target cube additionally enforces its destination port history pulled
back through the target's flip mask. These are necessary actual-H-history
conditions. They do NOT apply to arbitrary feasible five-macro words lacking
those port histories. The union over exact histories within a minimized class
is conservative; it must never be replaced by an intersection.

## Three-input disjunction

`bdd_v_three_backward.py` asks whether all three non-seam first-L cells of a
V, namely (-1,0),(-1,-1),(1,2), were read earlier in the concatenation. Its
backward state adds a three-bit need mask, initially111. A predecessor macro
clears every need bit for a marked cell it reads. Unlike the single-tip
last-writer checker, these transitions may read marked cells arbitrarily often.
Reaching need=000 with a nonempty color set is an abstract all-stale witness.
Exhausting the backward closure without doing so would prove the disjunction
for actual H histories. The colors at the chosen earlier interval entry are
otherwise arbitrary, so the check does not assume an originally blank board.

## Scope and output discipline

A finite-closure exclusion would be a theorem only after the geometry, port
provenance, BDD operations, and complete fixed point are independently checked.
An abstract witness is not a physical counterexample. The trace variant records
concrete macro words and region choices, and separately identifies geometric
mismatches when the exact endpoint displacement is replayed from its source.
A node cap is not an exclusion. All currently completed full-five tests are
inconclusive in one of these two senses.
