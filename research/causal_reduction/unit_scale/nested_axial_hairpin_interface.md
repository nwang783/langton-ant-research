# A minimal moving-center hierarchy has no local interface

23 October 2026, 13:58 UTC. Author literal complete finite check, pending independent replay. This is a fixed substitution-body result, not a general hierarchy exclusion.

The signed axial component has U=RRLRRRRL, V=LLRLLRLL and image W=U b V with b of physical type N-R at index8. Its recursive shift is(2,0). A genuinely new escape from the fixed-center wrapper theorem would put a perpendicular recursive component at moving centers along this ray.

The precise smallest attempted interface is this: at any nonempty subset of the eight odd-heading slots of W, replace the identity read by a separately decorated perpendicular axial component of exactly the same physical type. The slot indices are1,3,5,7,9,11,13,15. An R slot gets U c V with the corresponding rotation. An L slot gets swapRL(U) c swapRL(V); this is the reflected/complemented local component, with its own physical L base. All other children, except b itself, remain identities. Each c has no decorated descendants beyond itself. The components therefore have moving centers along b's ray and genuinely two-dimensional read footprints at higher depths. Each macro preserves its exact unit pose.

There are exactly255 nonempty slot subsets. Every resulting depth-two b image has a repeated equal turn at one cell, and hence cannot be realized on ANY initial coloring. No depth cutoff is used to infer a positive result: each model has an explicit finite counter-witness. A depth-two word has length33+16m for m selected slots, so all witnesses occur in words of length49..161.

Files check_nested_axial_subsets.py and nested_axial_subsets.json retain every subset and its first conflicting read pair. The separate probe_nested_axial_hairpin.py/json records the eight single-slot cases. The empty subset is exactly the signed all-r positive axial component and is intentionally not excluded.

This rules out only decorating these supplied eight slots with these supplied perpendicular components. Simultaneous insertion is included because isolated failures alone would not exclude mutual repair. Different component bodies, extra nonidentity work, moving centers arising through a different hierarchy, or nonstationary substitutions remain open.
