## Why this is a distinct construction class

An absolute-direction substitution can stretch horizontal and vertical coarse
steps differently. Here its uniform length is 17 and its endpoint matrix is
A=diag(3,5): E,W images have displacement (+/-3,0), N,S images (0,+/-5).
Each image alternates horizontal and vertical unit moves, beginning on the
same axis as its letter. Unlike a relative-turn substitution with rotated
images, it need not commute with quarter rotation. It is an expanding
rectangle, not a Gaussian-scalar dilation. Its spectral radius5 is below its
time radix17, so any all-time finite-support realization would be genuinely
aperiodic.

Every image contains all four absolute directions. This follows from its
fixed movement counts: an E image has E6,W3,N4,S4, a W image E3,W6,N4,S4,
a N image N7,S2,E4,W4, and a S image N2,S7,E4,W4. In particular all resulting
substitutions are positive/primitive.

## Exact image inventory

`rectangular_inventory_k17_3_5.json` enumerates horizontal and vertical
images, retaining one iff it is internally ant-legal for at least one of
its two possible perpendicular incoming headings. That is necessary for any
occurrence on any board. Each image is enumerated by choosing the positions
of west/south moves among the prescribed horizontal/vertical slots. There
are548 images for each horizontal direction and496 for each vertical
direction. Half-turn partners are generated by adding2 modulo4 to each
compass direction. N,E,S,W are encoded0,1,2,3.

No initial-white or finite-fuel assumption is used in the rejection tests.
Two consecutive same-cell turns of the same sign are impossible on ANY
initial coloring. A class rejection based on such conflicts is therefore
stronger than a finite-support rejection, but still only concerns this
explicit controller family.

Because each image contains E and the substitution is primitive, an
ant-illegal E-root factor excludes the same substitution language from any
other root or shift as well.

For a fixed root image, the macro sequence of phi^2(E) is known. The search
visits its17 image slots in order. Whenever a direction image is first
needed, it branches over its entire domain and keeps that assignment for
all later occurrences. At every read it records the last turn at the
physical cell and prunes exactly when the required turn equals that last
turn. All changed last-turn entries are restored in reverse order on
backtracking. Macro endpoints are independent of their image choice, but
the actual final heading is retained. Each complete assignment reaching the
end is a genuinely legal289-read prefix.

branching on a controller image only when that state is first encountered.

change a prefix before the first encounter of its state. Thus a conflict
prunes all completions of those still-unassigned controller images.
