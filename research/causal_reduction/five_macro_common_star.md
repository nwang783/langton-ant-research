# Full five-macro restriction at the common four-edge star

## Status and elementary simplification

The finite certificate below passed independent audit. However, its statement is a direct consequence of the literal macro seam: every macro ends RRRR and the next begins LLLLRL. In fact the common node6 is always parented by the immediately preceding terminal star, via its second token consumed forward. See `macro_seam_identity.md`. Thus this is not a substantive new global restriction; the certificate is retained as an independent computational check.

## Exact statement

For any physically feasible finite concatenation of C,V,U,Q,B, consider a macro's common phase-5 L at local cell (1,0). The cursor node it creates is the common four-R node beginning at phase 6.

If its consumed token was produced inside this macro interval, its producer node is necessarily one of

`C11, V14, U24, Q60, B70`.

The last four are exactly the terminal four-R stars of the non-C macros. If the producer is C11, every complete macro strictly between that producer macro and this consumer macro is C.

This statement does not assume freshness of any terminal star, bounded lifetimes, the actual H-port grammar, or a finite initial black board. It uses only physical same-cell color consistency and the literal five turn blocks.

## Certificate

`certify_five_macro_phase6.py` is a complete finite-color checker. It uses the same nine-cell patch {0,1,2} x {-1,0,1} as the C/V/B genealogy certificate. The full center lattice is now generated by (1,1),(1,-1), not the determinant-ten C/V/B sublattice. The exact sensitive-center equation retains 321 head states including OUT.

The forbidden-producer initial set has 745 complete-color states and its full conservative closure has 73,348 states. No reached state permits any normalized target macro.

The C11 separation test has 108 initial states and 73,232 reached states. A flag records an intervening non-C macro. OUT may set this flag nondeterministically, so an omitted excursion cannot conceal such a macro. No flagged state permits any normalized target macro.

All external colors are unconstrained, and OUT may return to every retained head with an omitted predecessor. These are overapproximations. The absence of a target is therefore sound. The checker separately tests closure and target exclusion and saves both reached-state lists in `five_macro_phase6_certificate.json`.

## Interpretation and remaining gap

The common nonterminal star cannot regenerate from arbitrary old local writes: its only non-C genealogical sources are terminal exit stars. The C11 alternative cannot carry ancestry across a non-C macro. This identity is built into the macro definitions and does not itself narrow the global stabilization gap.

It does not prove the terminal exit stars are fresh roots. Nor does it yet classify ancestry entering the other internal Q/B stars. A proposed global height bound still requires those renewal routes to be controlled. The exact finite closure passed independent replay and geometry audit; see `../audits/five_macro_snapshot/`, `../audits/audit_five_macro_geometry.py`, and `../audits/five_macro_replay.log`.
