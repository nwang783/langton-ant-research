# Transverse standard-wake crossing program

Scope: exact clean crossings, not arbitrary finite-seed dynamics. Incoming
backward-infinite standard wake plus one static bilateral settled standard wake
at a perpendicular angle. These infinite-background models isolate the mature
local interaction; a separate finite-seed realization/guard is required.

Goals:
1. Normalize relative lattice placements into finitely many classes.
2. Simulate only to discover recovery words or obstructions.
3. Prove any claimed infinite output by exact parity queries on periodic lines
   plus finitely many changed cells; no horizon-based capture claims.
4. Determine which output guards permit finite old wakes and arbitrary remote
   debris, and whether crossings can create side effects invalidating closure.
5. If a result is stable only on infinite input, state that explicitly.

Two perpendicular chiral orientations are retained separately. For full diagonal
drifts (-2,-2) and (-2,2), the lattice generated by them has index eight. A useful
relative representative is (a,s-a-4n), with a in {0,1}, s in {0,1,2,3}. Initial
separation n is not a ninth state variable once an exact mature first-contact
field equivalence is established. This normalization still needs checking.
