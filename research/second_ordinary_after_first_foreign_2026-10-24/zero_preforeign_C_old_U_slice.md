# A small exact SECOND-contact slice: old U and zero Cs before the foreign

## Statement and narrow scope

Assume the signed one-first-foreign/one-first-ordinary proxy theorem, and consider a chronological first new contact by the SECOND ordinary RAW chord. This note excludes only an outgoing OLD U-base source whose actual source-entry to foreign-entry C count n is ZERO.

The old U can lie anywhere in the preforeign old-eight history; it need not be its first packet. Its actual full type must be plain U: UC/UCC could not have completed before the foreign with zero Cs. The arbitrary earlier field/history remains retained. No postforeign maturity, old-star permanence across the foreign, or full returned-packet source reset is assumed.

No contact with n>=1, an older D/C/V source, a second foreign or a later RAW atom is excluded here.

## 1. Geometry forces the first returned atom to be raw C

The signed small second-atom interface has total ordinary clock N=n+1[b1=C]. For an old U source, alpha(U)=0. At N=0, a Jordan first contact would require alpha(U)>alpha(b2), impossible for any ordinary target. Thus with n=0, b1 MUST be C and N=1.

If b2=U, the actual raw C,U plus real following prefix has an immutable repeated-L contradiction. This is a literal local word exclusion, not a claim that C is a new complete-eight producer or that an age law crosses the foreign.

Only b2=D,C,V remain. All new contacts with foreign pieces, b1 or the last old V/U are already excluded by the signed small interface; the present proof only overapproximates all remaining old-U chord contacts.
