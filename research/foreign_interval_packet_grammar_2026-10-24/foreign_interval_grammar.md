# Actual foreign-interval packet grammar

## Exact restricted-language statement

If z is nonempty, then z contains a D/V/U base and its actual last atom is plain V or U. The only possible last-packet/foreign boundaries are VF, VQ, UF, UQ and UB. This is independent of earlier history, a U-entry, the entry field, proxy simplicity, whether A is the first foreign, or the length of z.

If z is empty, QF and BF remain literal possibilities. They must not be assigned an invented ordinary predecessor or excluded by a first-foreign ancestry premise.

## Why the arbitrary-length statement follows

If z contains no base, it consists only of Cs. Three initial Cs after A are excluded by three exact A CCC plus actual-M conflicts. When there are more Cs or another next word, that real next word supplies the same M11 prefix. One or two Cs before the next foreign are excluded by all eighteen actual ACB/ACCB immutable conflicts. The verifier records both actual owners of every failed request, including marker spill. Thus a nonempty z must contain a base.

Start at its first actual D/V/U base, keeping any leading Cs outside this selected factor. If this first base is D, it has a genuine preceding seven-atom RAW, either the leading C or source A. The ending cut admits the stipulated next complete foreign B and its actual M11.

Signed base-cut grammar 8a311a4c and its signed nonterminal extension 7ae212b4 therefore parse the SAME selected ordinary factor into the eight genuine packets D, DC, V, VC, VCC, U, UC, UCC. Packet boundaries and C tails are actual cuts. Terminal DCC is removed only because the next B really completes, not because M11 is mistaken for a full next packet.

The signed 24-pair packet/foreign table 735023be is rebuilt literally. Nineteen pairs fail, leaving exactly VF, VQ, UF, UQ and UB. Every packet ending C fails, and plain D fails. Therefore the actual final ordinary atom is plain V/U.

## Previous-C corollary, not a geometric induction

Every later foreign in an actual seven-atom factor has a consecutive-foreign interval immediately before it. For a nonempty interval its last atom is V/U; for an empty interval its previous atom is a foreign. Hence it is never immediately preceded by C.

If the factor begins at an actual RAW U, the same genuine nonterminal parsing argument handles the ordinary prefix before its first foreign. That first boundary is also one of the five allowed pairs. Consequently every foreign in this actual U-entry seven-atom factor has previous-C bit zero.

This is a literal grammar consequence. It imports no first-foreign geometric simplicity theorem, tag permanence, original-U maturity through a foreign or state reset. No tangent-clock or global-simplicity corollary is silently attached to it.
