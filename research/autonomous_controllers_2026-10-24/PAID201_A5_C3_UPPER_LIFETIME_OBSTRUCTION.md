## Transparent return-constrained prefix cover

The certificate supplies all2038 nodes of the finite prefix covers, including
both proposed heading branches at every nonterminal node and the reason for
every pruning. The only prunings are:

1. A fixed incoming or outgoing count is exceeded.
2. A literal physical first-return chain requires the next read to be a
   specified incoming ordinal, but that next read is not supplied.
3. A specified incoming ordinal has an exact first-return predecessor,
   but the immediately previous read is not that outgoing ordinal.
4. The outgoing endpoint's fixed next incoming ordinal disagrees with the

Each physical return path is stored with its full lifts and positions.

a small exact reachable-end-rank dynamic program. It permits every possible
gap between fragments. An empty final set is a checkable ownership/chronology
