## 2. Exact first-contact C horizon

Normalize the earlier contacted atomic entry to (0,0,N). Let its type be a in
{D,C,V,U}. Let n be the actual number of C atoms from that entry, inclusive
when a=C, to the foreign entry, exclusive. Let b be 1 precisely when the atom
immediately before the foreign word is C. The F-prefix direction angle is
alpha_F = pi + beta, where beta = atan(1/3).

For all four source types the direction difference satisfies

    pi/2 < Delta = alpha_F - alpha_a < pi.

At a first contact use the outgoing earlier chord and incoming F-prefix
chord, with source parameter 0 <= s < 1 and foreign parameter 0 < t <= 1.
The old simple subarc followed by the F-prefix up to this contact is a Jordan
curve. No old atomic chord is parallel to the F-prefix chord, so its closing
turn is unambiguous, including old-vertex contacts.

The internal turn along that subarc is

    n*pi/2 + Delta - 2*pi*b.

Closing by the principal tangent join makes the total turn

    2*pi*(ceil(n/4) - b).

A Jordan curve has total turn +2*pi or -2*pi. The negative possibility is
impossible: n is nonnegative, and b=1 implies n>=1. Consequently

    b=0 implies n in {1,2,3,4};
    b=1 implies n in {5,6,7,8}.                         (1)

In particular, the upper range 5..8 cannot be discarded. The actual C-to-F
principal join subtracts a full 2*pi. This is a first-contact horizon, not a
surviving-identity lifetime bound and not the old 294/330 C horizon.

## 4. The smallest prepared returned-star gate has a second clock branch

Consider the cycle analysis's specified prepared suffix, normalized to a genuine

    F entry (-5,-5) -> F exit (1,-3) -> D exit (3,-1)
      -> old-star center (1,1) -> source U start (-1,-1).

The last two legs are precisely the held original edges for cells (1,0) and

    (pi/2)*(n + 2 - 4*b) - pi/4,

where n is the actual source-entry C count and b is the immediately preceding-C

    (pi/2)*(n + 2 - 4*b).                              (2)

If, additionally, this entire natural closing curve is Jordan, (2) gives
exactly TWO branches:

    (n,b) = (2,0) or (6,1).

The second branch is genuine tangent bookkeeping, not a proposed physical
