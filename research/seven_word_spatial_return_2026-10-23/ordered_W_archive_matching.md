# Ordered, conserved W-archive submatching across the first foreign return

## Scope and statement

Assume an actual finite complete-eight factor beginning at a genuine U-family
entry, followed by its first complete foreign word F, Q or B and the immediately
returned RAW C. Retain actual birth identities, the full physical board, the
actual M11 continuation, and all unchosen residual ports. This note addresses
only the three necessary old-C first-return-contact interfaces of the signed
returned-C reduction. Normalize that old atomic C to (0,0,N). The foreign poses
are F(2,-5,E), Q(4,-5,E), B(5,-4,E), at old C clock 3; returned C starts at
(0,-1,W). An old fullproducer can contain that atomic C, so its containing
source and internal C index must not be replaced by an imaginary marked C.

After the containing source completes, let the remaining W stage contain N
actual fullpackets. Its length N is unrestricted. The final W base may own one
or two C tails; every earlier W base is plain D, V or U. There is a one-to-one,
strictly x-order-preserving matching from N distinct actual W-entry residual
identities to N distinct fresh common-output identities. Each matched output
lies strictly northeast of its matched input. All N common outputs remain
their original birth identities through this first complete foreign, returned
RAW C and actual M11 continuation.

Moreover the first W base must be D-family, and then the entire full-output
support of this W stage, including unmatched outputs, is disjoint from the
future foreign + returned C + M11 read context. This is direct unreadness,
not a claim that those other outputs cannot indirectly fund later S/E work.

Nothing here proves a decreasing full-board resource, bounded N, an arbitrary
W contact exclusion, or iteration across a second foreign or a later returned
atom. Dormant and unmatched ports remain in the physical board and ledger.

## Fullpacket ports and actual physical ownership

Use the actual fullpacket residual input and output masks. The specified input
ports, in the producer's N frame, are D/DC:(0,1), V/VC:(1,2), VCC:(0,3), and
U/UC/UCC:(-1,4). In particular VCC does not use the V/VC selected port.
Every fullpacket has common output (2,0), whose final actual RAW read is R at
zero-based tick 8. No own C tail revisits this site.

At W heading the common output offset is (0,2). The specified input offsets
are respectively (-1,0), (-2,1), (-3,0), (-4,-1), so output-minus-input is
(1,2), (2,1), (3,2), (4,3). All coordinates increase strictly in this matching.

The specified input's first physical L is at tick 11 for D/DC, tick 13 for
V/VC, tick 19 for VCC and tick 29 for U/UC/UCC. For plain D and plain U this
read is marker-only: the next actual word's RAW phase 1 owns it. For DC and
UC/UCC it is in that fullpacket's own C-tail RAW. Thus physical common-output
production can precede physical input retirement. The matching is the exact
fullpacket residual exchange, with input obligations and actual ownership
preserved. It does not assert physical L-before-R order.

## Actual W-entry funding and strict order

Write each W head as h_i=(-A_i,1+B_i). The plain W steps increase (A,B) by
D:(1,1), V:(3,1), U:(4,0). Therefore A increases strictly and B never decreases;
all these fullproducer entries have old C clock 1. An earlier producer within
this W stage must be plain, since a C tail would already end the W stage.

The checker reconstructs all 128 possible earlier-W-output to specified-input
alignments for the three plain sources and all eight full consumers. Exactly
64 are sector-inactive; the remaining 64 occur in the signed COUNT5 closure at
full source-entry age zero. None is possible in the actual factor. Hence no
specified W input is newly funded by an earlier W producer. By the exact
residual I/O chronology it is a distinct identity already current in the
residual at W entry. Core export would require a new output identity and is
not an exception. Actual input spending is once-only.

Pair each such input with that event's common fresh R8 output. All 24 adjacent
plain-source/full-consumer cases give strictly decreasing input x coordinates
and strictly decreasing common-output x coordinates. Event order is therefore
a strict x-order-preserving bijection of the two N-element lists. In particular,
for every upper-right-closed set P, the number of matched input sites in P is
at most the number of matched output sites in P. This statement concerns the
chosen matched subcohorts only, not total black mass or a complete profile.

## Survival of the common-output archive

The common outputs are q_i=(-A_i,3+B_i), so y(q_i)>=3. The signed atomic common
output theorem gives first later consumption at C age at least 3, measured
from the actual base/full source entry at old clock 1. At foreign entry the
age is only 2. Thus every q_i is current there, including outputs of the final
W fullpacket and its actual C tails. This uses maturity only before the first
foreign. The exact combined physical contexts of each foreign at its displayed
pose, returned RAW C and M11 have maximum y equal to 1. They never read q_i.
Consequently all q_i retain their original physical birth identities through
this finite excursion. No postforeign maturity theorem is invoked.

## Why the first W base is D and all W outputs are directly invisible

Every full-output slot has local y>=0. At a W head (-A,1+B), an output capable
of meeting a future context of minimum x=-3 must have A<=3. The exhaustive
head prefixes are empty, D, DD, DDD and V, at heads (0,1), (-1,2), (-2,3),
(-3,4), (-3,2). This is an all-length cone argument, not a prefix-depth cutoff.

All 1,020 output-slot/context queries leave exactly 45 hits. Every hit belongs
to the FIRST W base. They are V-family r=(0,0) or A=(0,1), or U-family r, A or
recycled q=(-1,2), and every corresponding future first read is R. In particular
each first V-family or U-family r is at global (0,1), required WHITE at the
future first read (ticks 64,72,82 for F,Q,B in the combined context).

A first V-family r is current at foreign entry: all 207 age-0/1/2 retirement
alignments give 120 sector exclusions and 87 signed COUNT5 exclusions. A first
U-family r is current by the signed old-eight permanent-left-star theorem.
These are preforeign protections. Its future first R is incompatible with that
current black identity, since the combined context contains no earlier read
that could remove it. Thus the first W base cannot be V or U; it is D-family.

With this first-D restriction none of the 45 possible direct hits is available.
Every actual W full-output site misses the future context. Later S/E producers
can still consume unmatched W outputs and create different visible sites. The
ordered matching neither deletes this indirect channel nor treats its outputs
as an automatic decreasing resource.

## Reproduction and scope boundary

Run check_ordered_W_archive_matching.py. Its JSON retains all 128 funding,
24 strict-order, 1,020 visibility and 207 young-r queries, exact contexts and
physical input ownership. Dependencies are hash-bound in the JSON and manifest.
The theorem applies to every finite W length under the stated first-foreign
history, with no bounded-support deletion or finite-state quotient. The
next foreign can read these common outputs or change the relevant clock, so
this note supplies no second-foreign invariant.
