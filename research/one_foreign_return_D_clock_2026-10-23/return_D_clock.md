# A returned D/DC old-w effect needs at least eight preforeign Cs

23 October 2026. Author-frozen for independent review.

## Precise case and result

Track the original fresh U-star identities from a genuine U/UC/UCC at (0,0,N), through an uninterrupted complete-eight interval to its first foreign A. Assume A's COMPLETE context misses all four original tags, so they survive as the same current residual identities outside its changed exit core.

Suppose the immediately returned full packet is D or DC at (0,2,S), using original w=(0,1). The uniquely determined foreign entries are

    F(4,4,N), Q(4,6,N), or B(3,7,N).

The foreign source-entry C clock must be at least eight. This is a necessary lower bound, not an attained example or an all-age exclusion. D absorbs w at RAW exit and the following word physically reads it at phase 1; DC itself owns the corresponding RAW phase-11 read.

## Clock zero

With no C, the creating full source must be plain U and all later old bases have heading N. The exact head equations are x=d+v, y=4+d+3v+4u. F(4,4) and Q(4,6) have no nonnegative solution. B(3,7) forces precisely three D bases, so its last old packet would be D, whose literal adjacency to B is impossible. Thus all six D/DC suffixes exclude clock zero.

## Clock four: Q and B

At Q(4,6,N), original creator exit bud s=(1,3) is foreign-local (-3,-3), first read Q RAW58 R. At B(3,7,N), it is local (-2,-4), first read B RAW68 R. Both before-requirements are WHITE.

The genuine creating U's s was born at RAW26 R, is preserved by source UC/UCC tails, and by the signed creator-exit-bud theorem cannot retire inside the old-eight interval through source-entry C age four. Therefore the same actual source identity is still black at foreign entry, contradicting each first before-white read. No permanence is used during the foreign itself.

## Clock four: F

F(4,4,N) requires b=(2,4) WHITE at local (-2,0), first RAW44 R. This b is genuinely born as the common R8 output of the FIRST actual atom after creating U BASE, at (0,4,N), clock zero. That first atom can be D, V, U, or the internal C1 in UC/UCC; its actual clock is not shifted to the source full exit. The signed common-bud theorem gives minimum first-retirement age three and preserves b through any remaining source tail.

The only possible actual last complete-eight packets before F are plain V or U. Their entries are V(3,1,N) and U(4,0,N). Neither can consume b itself, so a full bud consumer must complete before that last packet enters.

Reconstruct all eight D/V/U residual-input roles at ages three and four, separately for these two last-entry targets: 32 exact endpoint cases.

- At age four, every N consumer base endpoint has y>=4. No remaining zero-C N motion can reach either target height 1 or 0.
- At age three, the heading is E and every endpoint has x>=2. The required C4 adds one to x. For target V(3,1), only the three endpoints (2,3,E) fit the x budget, and C4 already leaves y=3>1.
- For target U(4,0), endpoints with x>3 exceed the x budget after C4. Endpoints with x=3 have y=4. An endpoint (2,3,E) leaves only one extra x unit beyond C4: using an E D can lower y only to two, while using N motion raises it. Every possibility remains above target y=0.

Thus b cannot have retired before either possible last old producer at clock four. It is still black when F's actual first before-white requirement demands white. This universal endpoint proof does not rely on the previously failed nineteen-cell extension or a capped zero-C search.

## Consequence and boundary

Foreign heading N forces the clock to be 0 modulo 4. Excluding clocks zero and four gives at least eight. All optional original C tails, complete bud-consumer completion, actual foreign before-masks, and changed-core/read ownership are retained.

This result concerns these six exact suffix cases only. It does not prove a simple returned path, exclude returned V/U old-w effects at clock four, extend star permanence through a foreign, or iterate clocks beyond the two necessary cases.
