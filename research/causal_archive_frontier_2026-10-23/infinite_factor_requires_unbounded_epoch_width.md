# An infinite U-entry factor would require unbounded epoch lengths and widths

23 October2026,20:16 UTC. Author analytic consequence submitted for review.
Scope is the actual retained-eight language and its signed U-entry simplicity,
not arbitrary ant paths or universal standard capture. The growing frontier
is not replaced by a presumed uniform one: the proof derives a contradiction
UNDER an explicit uniform-epoch-length hypothesis.

## 1. A simple translating periodic center curve cannot carry C atoms

Suppose a corrected-center D/V/U/C polygonal curve is injective for its whole
one-sided infinite duration, and a nonempty finite atomic word repeats with
its actual heading restored and a fixed displacement d. Let c be its number
of C atoms. Restored heading forces c to be a multiple of four.

If d=0, any repeat returns to the same actual center, immediately violating
injectivity. Suppose d!=0 and c>0. Let P be one finite period from A to A+d,
and let P_N be N translated copies. Every copy has the same bounded projection
onto the normal to d, so all P_N lie in one fixed infinite strip parallel to d.

Choose a fixed vector v far enough toward one side that the parallel line
A+v+R*d is outside this whole strip. Close P_N with the three segments

    A+N*d -- A+N*d+v -- A+v -- A.

The long middle leg misses P_N entirely. Each end leg has fixed bounded length
and bounded projection along d relative to its endpoint. If the one-period
path has d-projection in[alpha,beta], only a fixed number of translated periods
can meet either end leg, independent of N: their projections are
[k*||d||^2+alpha,k*||d||^2+beta]. A fixed bounded endpoint projection interval
meets only O(1) of these integer translates. Each period has finitely many
atoms, and a straight end leg meets each at most once.

Choose v generically in a small open neighborhood preserving its strict normal
separation. Only finitely many atom copies can meet the two end legs uniformly
in N; near the right endpoint translate them back by N*d. Thus the generic
choice avoids all unintended vertices, overlaps and tangencies. The closed
curve has at most K ordinary transverse crossings, with K independent of N.
The bridge itself is simple, being three sides of a nondegenerate parallelogram.

Resolve its crossings into at most K+1 simple Jordan polygons. Its turning index
has absolute value at most K+1. The signed atomic tangent lift gives open turn
pi*N*c/2 up to the same uniformly bounded endpoint term(<=3pi/4). The four new
closing corners contribute at most4pi in absolute value. Consequently

    N*c <=4K+13,

using the same integer rounding as the signed nearby-return proof, now with
four rather than three closing corners. This is impossible for c>0 as N grows.
Therefore no such infinite simple translating curve can have positive C count
per period. No white-front, visit cap, period bound, or prepared input profile
is used in this elementary geometric lemma.

## 2. Uniform epoch length would make the exact330 frontier uniformly finite

Assume for contradiction that an infinite actual complete-eight factor starts
U/UC/UCC and, after some clock J, every epoch has at most B packet starts.
Finite-C duration is signed, so its C clock tends to infinity. Let r0 and R be
the fixed finite entry residual count and entry radius.

Take cuts j>max(20R+271,J+330). Entry identities are then absent from every next
candidate context, and all surviving produced frontier ages lie in0..330.
Between any retained identity's full source entry and the current cut there
are at most331 recent epochs, each with at most B packets. Every raw packet
has length at most58 and every output slot has L-infinity norm at most7.
Thus every retained cell lies within

    K_B=58*331*B+7

of the current head. Its full-source age has331 possible values. Keep exact
head-relative colors/ages, heading, core, and the same finite packet-parser
state stipulated by the signed330 frontier. Absolute C clock is no longer
needed: entry expiration remains true and age updates use only the next
packet's zero/one/two C increment.

There are finitely many such normalized states. The signed330 theorem gives
a time-homogeneous EXACT candidate-packet transition relation, including all
WHITE guards, so the actual infinite retained path visits a repeated normalized
state. Preserve parser state exactly; no new arbitrary atomic words are added.

If the parser is deterministic this directly gives a periodic normalized tail.
More generally, choose the finite transition cycle appearing between two equal
states and repeat that SAME cycle. By the exact next-packet induction it is
physically valid on the true board from that actual state indefinitely. Hence
it gives the same deterministic physical ant continuation, regardless of any
purely representational packet-choice ambiguity.

The cycle has fixed head displacement d and restored heading. It cannot have
zero C count: repeating it would give an infinite zero-C epoch on a finite
actual entry board, contrary to the signed zero-C fuel theorem (or finite-C
duration). If d=0, actual U-entry center simplicity is violated. If d!=0,
Section1 excludes its positive-C simple translating center path. This is the
required contradiction.

**Conclusion.** Every hypothetical infinite U-entry retained-eight factor has
UNBOUNDED numbers of packet starts per C-clock epoch. This is not assumed as
a premise or inferred from unbounded elapsed time alone.

## 3. Parallel production forces unbounded transverse base sweeps

Use the separately submitted causal width transport inequality after entry
input expiration:

    N_j <=5292+3*sum_a(v_a+u_a),

where a ranges over at most147 even-age parallel source epochs, v_a/u_a are
their V/U base counts, and permanent U left-stars are not spendable. Its coarser
form without the permanence refinement is

    N_j <=5292+3*sum_a(v_a+2u_a).

Since Section2 makes N_j unbounded along some sequence of clocks, at least one
recent source epoch must have unbounded v_a+u_a (using permanence), and in any
case unbounded actual transverse base sweep

    W_a=2v_a+4u_a.

A bounded normal corridor cannot support an infinite such retained factor
merely by making its D runs longer and longer. Longitudinal active-memory
escape must be accompanied by growing young parallel V/U production and actual
transverse width.

This still does not bound that widening or exclude its renewal. It gives no
original-mass defect budget, no bound on independent U-chain births, and no
proof of universal capture. The outstanding possibility is a genuinely
nonperiodic, widening produced frontier, not a hidden bounded-state cycle.
