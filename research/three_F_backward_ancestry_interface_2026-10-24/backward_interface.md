# Why canonical backward reanchoring does not yet close the three-F problem

This is an exact interface assessment, not an exclusion of the fourteen remaining cases or a theorem that no future stateful ancestry map can exist. No new prefix search is performed.

The signed parent reduction1905984f leaves:

- D15: last positive-C parent DC/VC, then empty,D,DD,DDD,V;
- D30: last positive-C parent DC/VC, then D,DD.

A useful well-founded argument would map one of these actual histories to an earlier creating source while preserving the same problem, every birth tag, actual head/core, source clock, contact owner and ordinary/marker ownership. Strictly earlier source time alone is not enough. The exact natural reanchoring attempts fail as follows.

## Back to the last positive-C parent

Each retained parent is DC or VC with its actual base heading E. Normalize that earlier base instead of the later selected D. All fourteen rebasings now have:

- foreign F normalized heading N, not the E required by every three-F template;
- returned C/V normalized heading S, not W;
- source-to-foreign C distance FOUR, not THREE;
- actual first-contact owner still the LATER selected D, not the parent D/V base or its C1.

The creating source has strictly decreased, but the typed problem has changed. The new source-to-contact atomic offset is2 plus the short-run length. No source-first-contact age catalogue applies to that non-owning creator simply because its output ancestry is earlier.

## The tempting D15-to-C75 near-match

If the preceding N run ends with plain D, move origin to that strictly earlier D at(-1,-1,N). D15's head poses become EXACTLY F(3,-4,E), returned C(1,0,W), matching the C75 containing-D geometry.

But its contact point becomes(1,1), the END of the older D. The actual outgoing atom there is the later selected D. C75 instead requires the actual outgoing C1 START of a genuine DC producer. The older packet here is PLAIN D because it belongs to a zero-C N run. It has no C1 to own this contact.

This distinction cannot be removed by the fact that D and C have the same corrected-center displacement. Compare actual DD+M11 against hypothetical DC+M11. Their first physical disagreement is zero-based tick21:

- actual DD RAW length20: following actual word tick1/read2, L;
- hypothetical DC RAW length25: own C-tail1 tick11/read12, R.

Actual DD ends at head(2,2,N); hypothetical DC ends at head(1,2,W). Both corrected END centers happen to be(3,3), but fine time, head/heading, C count and active-core/birth ownership differ. The substitution would change zero C increments to one and would not preserve the later target clock either. Thus this geometric near-match is not a legal backward reduction.

The JSON retains all six such near-matches (three D-run words times two parent species), not a single representative assumed to cover them.

## Other immediate backward steps

For D30, stepping back one plain D gives F(4,-3,E), returned V(2,1,W). The original contact becomes(2,2), the strict midpoint of the LATER D chord beyond the older D's endpoint(1,1). The returned segment does not contact that older D. This is not any of the three normalized F templates.

For the D15 preceding V case, the rebase gives F(3,-2,E), returned C(1,2,W), contact at the older V's END(1,5), again owned by outgoing later D. Relabeling it as an old-V source contact would discard the actual outgoing-vertex ownership.

All twelve nonempty-run immediate predecessor rebasings are recorded. None is claimed to inherit a source-contact theorem from an earlier atom that does not own the first contact.

## Exact data that grows or changes

The required enlarged interface must retain at least:

1. The actual outgoing-contact owner and its atomic/fine offset after the earlier producer. This is not the older producer label.
2. The source-to-foreign C distance and heading phase. One positive-C boundary backward raises distance3 to4; older positive-C boundaries can raise it further. The first-contact horizon does not bound the age of a non-owning ancestor.
3. The relative foreign normal and pose. One plain N D backward increases foreign x+y by TWO without changing C age; one plain V increases it by FOUR. Repeatedly replacing origins is not a normalization within the same finite three-F template class.
4. Full head/core and last-R ownership, not just corrected centers. The DD/DC countercheck demonstrates a concrete center alias with incompatible literal histories.
5. The genuine residual/active-core ports of the older DC/VC producer and the retained intermediate words. No cancellation or uniform bound on that older history has been proved.

This does NOT prove that every conceivable causal ancestry map is impossible. It identifies the exact failure of the direct earlier-source reanchor and the specific data an improved well-founded map must control. No induction is asserted until an actual map preserves those fields.
