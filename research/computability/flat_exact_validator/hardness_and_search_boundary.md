# What the integrated fixed-presentation decisions do and do not imply

2026-10-23 07:24 UTC. Logical consequences, not a new ant universality theorem.
The unit additive-I and finite-order decisions are signed KJ/KK. The broader
arbitrary-branching finite-base macro implementation is separately under review;
its analogous conclusions below apply subject to that exact theorem's signoff.

## 1. No faithful undecidable compiler into this exact target

Suppose a total computable compiler sends an arbitrary machine/program e to a
finite heading-compatible, nonerasing fixed unit presentation with a finite-
order spatial matrix, actual first-letter root cycle and selected root limit.
Suppose it promises

    e halts  iff  SOME finite board realizes that selected presentation.

Compose the compiler with the signed realization decision. This would decide
halting, a contradiction. The same obstruction holds with the equivalence
reversed, or for the signed c.e.-complete Presburger parity-graph target.

The alphabet, image lengths, offset magnitudes and realizing seed mass/radius
may all vary with e; uniform decidability takes the whole finite presentation
as input. Hiding unbounded BUT FINITE complexity in a new label set, very long
image, remote unread cell or unknown seed mass does not evade it. A declared
finite-order period can be checked; if the compiler supplies only the finite-
order promise, enumerating its matrix powers finds one effectively.

If the finite-base macro extension is approved, the same argument covers
arbitrary finite MULTI-READ macro states with fixed full poses, including zero
or non-unit displacements. Merely grouping a long finite gadget into one
recursive label then does not reopen a halting reduction inside that class.
This is an architecture boundary, not a statement about arbitrary finite ant
seeds or unrestricted simulation.

A useful actual finite-support universality construction must therefore not
claim this specific stationary finite-order realization problem as a faithful
hard target. It would have to change an essential hypothesis or reduce a
DIFFERENT question. No broader compiler is supplied or excluded here.

## 2. A positive growing certificate would still refute capture

For the verified cofinal spatial-I/root-fixed power, every root prefix ends at
its same fixed full pose and displacement. A genuinely growing accepted root
would give an actual finite-seed trajectory with infinitely many returns to
that finite pose set. It cannot have an eventually periodic nonzero-drift tail.
A zero-drift periodic tail is excluded by finite-domain escape. Thus it would
be a genuine finite countermodel, not just a different highway period.

No accepted control has a growing root. Positive stable, transient and cyclic
finite families are deliberately flagged nongrowing and provide no evidence
against capture.

## 3. Restricted constructive search is recognizable, not automatically finite

One can enumerate all finite syntactically valid exact-pose presentations,
orders and root cycles, apply the exact per-presentation decider, and retain
positive growing ones. If a finite countermodel has a certificate in this
restricted class, that unbounded enumeration eventually finds it. If none
does, the search need not terminate. Deciding each fixed candidate is not a
uniform finite bound on how complex the correct candidate could be.

This does not make noncapture recognizable for arbitrary finite ant seeds,
because no theorem says every noncapturing trajectory has such a finite
presentation. Nor can a long simulation substitute for its exact all-depth
forced-color and frame checks.

Real implementations can exhaust memory or hit explicit algebra/enumeration
caps; those outcomes remain UNKNOWN. They do not change the mathematical
termination theorem for the uncapped exact procedure, and cannot be counted
as negative evidence. The preserved dense-read-set exit137 experiment is one
such resource outcome. Its later valid selected-color rejection is a different
proof route, not retroactive interpretation of the failed computation.
