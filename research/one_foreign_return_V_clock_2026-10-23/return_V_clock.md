# A returned V/VC old-w effect also needs at least eight preforeign Cs

23 October 2026. Author-frozen for independent review.

## Exact case

Start with a genuine U/UC/UCC at (0,0,N), then an uninterrupted actual complete-eight interval, its first foreign A, and immediately V or VC at (0,4,S). A's COMPLETE context misses all four original star identities, so original w=(0,1) remains a true residual input at the returned entry rather than having been absorbed by A's marker slot.

The foreign entries are exactly F(4,6,N), Q(4,8,N), or B(3,9,N). Their source-entry C clock must be at least eight. This is a necessary bound, not an attained example or an all-age exclusion.

Plain V's first physical read of original w is returned phase 19, outside its eighteen-turn RAW, owned by the following word's phase 1 after V's exit-core absorption. VC owns that read inside its own C tail. Nothing here assigns it to the wrong RAW word.

## Clock zero

Foreign heading N permits clocks 0 modulo 4. At clock zero all old bases have heading N and the creator must be plain U. The exact head equations x=d+v, y=4+d+3v+4u give:

- F(4,6): no nonnegative solution;
- Q(4,8): four D bases only, whose last packet cannot precede Q;
- B(3,9): two D plus one V, with no U, so it cannot have B's required last plain U.

The signed exact local adjacency table permits only plain V/U before F/Q and only plain U before B. Thus none of the six suffix cases can have clock zero.

## Consequence and limitation

Foreign heading N forces clocks 0 modulo 4. Removing zero and four gives a lower bound of eight. The checker reconstructs all six foreign/returned-packet rows and the four actual first-atom interfaces, including the terminal-center equality and the fresh phase-4 births.

The argument does not assume the returned V chord is simple with the old path. It uses only the already signed simple path through the FIRST foreign, and preforeign genuine birth histories. It does not prove actual old-star erosion at clock eight, returned-U cases at clock four, a second-foreign extension, or seven-word termination.
