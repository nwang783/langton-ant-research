# A universal twenty-four-string prepared interface for exceptional returns

23 October 2026. Analytic consequence of exceptional_arbitrary_base_return_map.md,
submitted for independent review. Conditional interface criterion, NOT a claim
that every finite perturbation of this background captures.

## 1. One fixed prepared background, arbitrary finite old cap

Use the exact return map and masks L=P XOR C XOR(C+d) from the companion note.
Translate its fixed section by -Kd. Its COMPLETE return states are exactly

    Z_n = (G_X XOR P_[0,n) XOR(C+n d), r,h_R),          (1)
    P_[0,n) = XOR_{i=0}^{n-1}(P+i d),
    G_X = shift(-Kd,A_X) XOR C.

All dependence on the arbitrary capturing base is now in ONE finite cap G_X.
The pose, d, P, C are universal canonical data. P has one point in each of24
distinct full-drift orbits, so P_[0,n) is exactly24 disjoint length-n strings.
Define the fixed infinite prepared background

    T_24 = union_{i>=0}(P+i d).

The complete states Z_n converge locally to

    Z_infinity = (G_X XOR T_24,r,h_R).                 (2)

The limit is not a finite board. In general G_X is a finite XOR cap, not
additions-only, even though the original remote obstacle was one black
addition. No cap bit or old archive is discarded.

## 2. Exact finite truncation discrepancy

The difference between(1) and(2) is

    D_n = (C+n d) XOR union_{i>=n}(P+i d).             (3)

It is confined to a fixed finite cap translated by n d and24 rays starting
at the receding positive-d endpoint. Thus no arbitrary geometric remainder
is hidden in the limit.

Suppose the ACTUAL trajectory of(2) has a standard104 tail of full drift f.
Its entire future read set is a finite set plus finitely many rays with
forward direction f. If f is not a positive multiple of d, that complete
read set misses(3) for all sufficiently large n. The signed companion cone
argument applies with the direction reversed: an unbounded intersection
would require l f-k d bounded with l>=0 and k>=n, possible only for f parallel
to +d. For standard104, the unique exceptional direction is f=d.

First-difference induction therefore makes every sufficiently large Z_n
follow exactly the entire future of(2), hence capture, with uniformly bounded
post-section K count. True initial inverse histories also agree for all
sufficiently large n by local convergence and reversibility; alternatively
allow10 additional initial boundary events. If a complete prepared-interface
tail certificate for(2) is supplied, the cutoff is effective by finitely many
integer ray-intersection tests.

## 3. Necessary alternatives for a bad exceptional family

If this fixed-base exceptional singleton family has unbounded actual future
K counts as n grows, its prefix through the return section costs a fixed
number of K for n>=1. Consequently at least one of the following is necessary:

1. the one fixed24-string prepared state(2), with its finite inherited cap,
   has a nonstandard future;
2. it captures standard with output directed exactly toward the receding
   remote endpoint, f=d, so finite truncations can later contact that endpoint.

Neither is a finite-seed counterexample or a sufficient condition for defect
unboundedness. In particular no finite-K/capture equivalence is imported to
(2). The alternative f=d is a clean standard outbound flight until a possible
endpoint collision, not a large-defect episode by itself.

This supplies a precise next scattering problem: one universal two-wake
prepared background plus an explicitly computed finite inherited cap, followed
possibly by a remote-endcap return. A global nonlinear budget must retain this
interface and its endpoint, rather than pretending that the first reverse
arrival restores a bounded finite board or erases its two rail wakes.
