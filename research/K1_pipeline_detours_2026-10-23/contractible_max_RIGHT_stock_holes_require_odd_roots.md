# Every contractible max-RIGHT stock hole has an odd-output root

Pending independent review. This uses the separately frozen canonical

Let H be any family of DISTINCT CONTRACTIBLE canonical sheet M-1 nodes,
each with a repaired RIGHT corner around a global maximum C face M.
Let h=|H|, Ntop count odd output classes incident to a global-max C face,
and J count source-sink path components of G3(M), so its endpoint count
is 2J. Then

    h <= Nodd-Ntop+J = Nodd-Nshallow-J.

In particular Nodd=0 forbids EVERY such contractible node, with arbitrary
graph degree. The nonleaf cycle-rank escape is unavailable in that scope.
No initial-fuel bound or exclusion of essential middle nodes follows.

## 1. A contractible penultimate disk contains no maximum C face

A contractible canonical node lifts to a simple closed rounded physical
Jordan curve gamma. The sheet-j C barrier at j=M-1 preserves the entire
C superlevel >=M, that is every global-max C component, on one side of
gamma. Each such maximum component contains an essential canonical
first-L parent curve, by the signed WHITE maximum-plateau theorem. It
cannot be confined to a bounded physical disk. Therefore the disk
bounded by gamma contains NO global-max C face center.

If gamma has a max-RIGHT corner, its adjacent max C face is on RIGHT.
Thus the disk cannot be RIGHT; gamma is COUNTERCLOCKWISE and its LEFT
side is the bounded disk D. This agrees with signed a2170bdc, now with
an explicit C contact barrier for every penultimate contour.

## 2. The bounded LEFT disk contains a strict low L face

At a max-RIGHT corner normalize the equal R headings to E. Its higher
C height is M and the other C height is M-2. If l_E,l_W count its one
or two L headings, its incident L heights are

    M-2-l_E, M-2-l_W.

At least one is <=M-3. The unique sheet M-1 arc is RIGHT around the
higher C sector, because the other C sector is below M-1 and both L
sectors are below M-1. Both L sectors lie on its geometric LEFT side.
Consequently at least one L face of height<=M-3 lies inside D.

The separate L barrier says that an L sublevel component <=M-3 cannot
cross gamma, including through a four-port primal corner. In particular
this low face belongs to a physical sublevel component confined to D.

Choose an L face of minimum height m among all L faces inside D, and
let Q be its entire connected plateau at m. Then m<=M-3. The barrier
confines Q to D. Any lower L face corner-adjacent to Q would also have
height<=M-3 and would have to lie inside D, contradicting the minimum.
Thus Q is a locally MINIMAL L plateau in the full plane, not merely a
minimum after artificially cutting its boundary.

Q is physically finite and cannot have essential winding. More
explicitly, if Q met a nonzero full-drift translate of itself, the two
connected same-height components would coincide, forcing a finite
physical set to be periodic under nonzero drift. Hence projection into
the actual full quotient cannot hide an essential cycle inside Q.

By the signed reverse prepared-plateau theorem, a locally minimal L
plateau with no odd-output incident corner has an essential reverse
first-L curve. That is impossible inside D. Therefore Q touches an
original ODD-output cell. This is a necessary final-output root, not an
original black-input root and not a paid renewal.

## 3. Distinct max-RIGHT stock holes have disjoint bounded disks

Take all physical lifts and full-drift translates of nodes in H. Their
canonical sheet circles are pairwise disjoint. Two bounded Jordan disks
are therefore disjoint or nested. Nesting is impossible: an inner
max-RIGHT circle has an adjacent max C face on its RIGHT side, still
inside the outer disk. This contradicts section1 for the outer disk.

The same argument prevents nesting of different translates of one
contractible node. Thus the entire lifted family has pairwise disjoint
bounded disks. This step counts DISTINCT nodes; repeated use of a node
is not given a new disk or a new resource.

An odd physical cell cannot root minima in two of these disks. If its
same incident L face did so, the disks would intersect. If its two
incident L faces did so, both would have height<=M-3; their retained
diagonal contact lies in the complement of all penultimate circles by
the L barrier, so the two faces cannot lie in different disks. This also
handles minima at different low heights.

The argument is full-drift equivariant. If two root classes coincided
only after a drift translate, translate the associated disk too. The
physical nonoverlap just proved forces the two canonical node classes
to agree. Hence there is no short-quotient alias or hidden reuse of one
odd output for inequivalent holes.

## 4. A top root is paid by a complete same-R output pair

A top singleton has L levels M-1/M-1, and a top opposite-R three-read
class has L levels M-1/M-2. Neither can touch Q at m<=M-3. Thus a TOP
odd root must be a same-R three-read class, and necessarily m=M-3.
It is an endpoint of G3(M).

The signed G3 endpoint pairing preserves its SAME connected L plateau,
so its paired endpoint touches this same Q. That complete finite path
component cannot pay a different stock-hole disk. Distinct holes paid
by top roots therefore reserve distinct components among the J paths.
Holes paid by non-top roots instead reserve distinct classes among the
Nodd-Ntop non-top odd outputs. The two payment types are disjoint.
Choosing a non-top root whenever available proves

    h <= Nodd-Ntop+J.

This does not add two new endpoint payments to existing output budgets.
The same G3 paths may already occur in another necessary inventory; the
claim is a capacity for the actual disjoint stock-hole interiors only.
