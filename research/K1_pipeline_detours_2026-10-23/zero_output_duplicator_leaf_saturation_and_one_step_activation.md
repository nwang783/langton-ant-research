# Zero output saturates the duplicator-to-leaf matching

23 October 2026. Complete WHITE cap-four translating front, actual full quotient. Assume N_odd = 0. This is a conditional structural lemma, not a proof that zero output or general K = 1 fronts are impossible.

## 1. Exact saturation

The signed output partition gives

    0 = N_odd >= N_O + D_C + D_H + D_S.

Thus N_O = D_C = D_H = D_S = 0, and every actual positive duplicator is of the all-four type D_4. The canonical flag identity gives exactly D_4 negative units.

Every such duplicator has a distinct associated flag-one canonical I leaf. There are already D_4 of these leaves, each carrying one negative unit. Hence they exhaust ALL negative flag units. In particular:

    every q = -1 face is one of these terminal I leaves;
    every flag-one canonical leaf equals I(D') for a unique
    actual positive all-four duplicator D'.

Uniqueness is the signed physical D -> I injection, not a choice of a nearby D-shaped face. This argument uses actual positive duplicators with both canonical children. It does not promote every local D-shaped profile to a duplicator automatically.

## 2. A genuine one-step activation in the outward late route

Apply the new outward-Q1 leaf theorem to an actual late route D -> J -> P0 -> I with Q1 at M. Its four possible Q1 births reduce as follows under zero output:

- Both SSNS/EEEW modes are impossible: their Q1 leaves are disjoint from every D-associated I.
- The NSSS/EWEE mode with NW canonical entry is impossible because it contains a singleton-R output corner.
- The remaining NSSS/EWEE mode has the all-four physical Q1 profile

      k = EEWE, j = NNNS, f = EWEE, g = NSSS.

  Saturation forces Q1 = I(D') for an actual positive D_4. The exact physical recovery in the new theorem gives D' = P0.

Therefore P0 is not merely a local D-shaped face: it is an ACTUAL positive duplicator. Its left contact x = WWEW is now an actual canonical child contact, in addition to its known right child I. Writing R = (-3,-1),

    p(R) = P0, p(I) = P0,
    p(P0) = J, p(J) = D.

The first equality was only a possible local child before the saturation argument. It is now forced. If D lies on Gamma and J is its off-cycle child, P0 and R remain off Gamma by canonical-parent uniqueness. Births strictly increase along D -> J -> P0 -> R, but no repeated local package or new component is inferred.

This is a conditional one-step activation, not an infinite left-regress argument. In particular P0's own opposite leaf Q1 has parent (-4,0); the proof does NOT establish that this parent is a child of R. Thus it does not establish another late route of the same form.

## 3. Retained alternative for an exact late Gamma route

Under zero output, the strict-pit case of the signed LEFT localization theorem supplies disjoint lower counterflow and P >= 18 ||d||_infinity. The outward case instead has the precise activated descendant P0 above.

Thus an exact late Gamma route has a conditional alternative:

    P >= 18 ||d||_infinity;

If the period bound fails, the activation follows, but the off-Gamma descendant is a genuine remaining finite forest resource. No original fuel, repeated-parent mechanism, unconditional K rise, general K = 1 exclusion or all-cap conclusion is claimed.
